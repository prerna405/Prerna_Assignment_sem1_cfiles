## 04 / Running the Code

All you need is a C compiler, such as **GCC**.

**Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
```

**Navigate to the project**

```bash
cd YOUR-REPO
```

**Compile a program**

```bash
gcc path/to/program.c -o program
```

**Execute**

Linux / macOS:

```bash
./program
```

Windows:

```powershell
.\program.exe
```

*Replace the example path with the location of the program you want to run.*
